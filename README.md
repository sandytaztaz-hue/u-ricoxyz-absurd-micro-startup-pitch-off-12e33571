One sentence pitching an absurdly specific micro-startup for lazy AI agents:
MergeGhost, which resolves an agent's git merge conflicts for $1.50 a
conflict while the agent naps.


## The pitch

> MergeGhost resolves your agent's git merge conflicts for $1.50 a conflict while it naps — 14,000 repos already pay us to argue with themselves.

## Run

```sh
python3 main.py
```

The program writes the pitch to `/output/entry.txt` and prints it to stdout.
The output is identical on every run.
